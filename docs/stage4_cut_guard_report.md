# Stage 4 验证报告：三步割生成判据 + 加班型排除守卫（供论文 §5.2.1 回填）

数据：V-toy-1 金标算例（`data/vtoy1.xlsx`）。
判据实现：`src/feedback/cuts.py::evaluate_cut_criterion`；
中间量由回归测试 `tests/test_regression_vtoy1.py::test_a10_*` 持续锁定。
判定求解器：CP-SAT 精确调度器（`src/scheduling/exact_cpsat.py`，最优性已证明）；
元启发式（vendor NSGA-II-VNS-MOSA）三种子重启作为判据①的实测佐证。

参数：T^avail=480，OT^max=120，ρ_min=0.8，N_restart=3，Cap^eff,(0)=名义产能。
可接受当且仅当 ρ ≥ 0.8 ⇔ C_max ≤ 480 + 0.2×120 = **504**。

## τ=1, k=0（q = A12/B8/C5，三族齐）—— 预期：不生成割 ✓

| 判据步骤 | 中间量 | 结论 |
|---|---|---|
| ① N_restart=3 重启 | 精确：C*_max=509（三种子同值，最优性证明）→ ρ*=0.7583；vendor 种子1/2/3 代表解：C_max=557.5/579.5/525.0，ρ=0.354/0.171/0.625 | 全部 ρ<0.8，Feas=0 → 通过。且 C*=509>504 证明**任何**求解器都不可能可接受 |
| ② 负荷排除 | 阶段负荷 (256, 465, 294) ≤ Cap^eff,(0) (960, 480, 960) | 不排除（负荷均在产能内） |
| ②′ 加班型排除守卫（§2.2 新增） | OT^{*,(0)} = max{0, 509−480} = **29 ≤ OT^max=120**（等价 ρ*=0.7583>0） | **判为加班型 → 不进入③，不生成割**；仅走通道1（Δc）+ 通道2（Cap^eff） |

无守卫时的反事实：③ 会对 τ=1 继续测试且移除任一产品均可行 → 生成过强割
C={A,B,C}，迫使某产品整体退出 t=1——与正文"加班时间过高…不新增割"意图冲突。
守卫消除了该冲突（金标 '8_P1判据歧义' 设计目的）。

## τ=3, k=0（q = B14/C6，{B,C} 深度换模冲突）—— 预期：生成割 ✓

| 判据步骤 | 中间量 | 结论 |
|---|---|---|
| ① N_restart=3 重启 | 精确：C*_max=678（下界核对：430×0.8+(10+280)=634 ≤ 678）→ ρ*=0；vendor 种子1/2/3：C_max=731.7/726.5/719.7，ρ=0/0/0 | 全部 Feas=0 → 通过 |
| ② 负荷排除 | 阶段负荷 (216, **430**, 224) ≤ (960, **480**, 960) | 不排除（430 ≤ 480，聚合产能充足 → 非负荷型） |
| ②′ 加班型排除守卫 | OT^{*,(0)} = 678−480 = **198 > OT^max=120**（ρ*=0） | 加班上限内不可消化 → **进入③** |
| ③ 单产品移除测试 | 移B → 仅 C6：C*_max=219，ρ=1 可接受；移C → 仅 B14：C*_max=301.6，ρ=1 可接受 | S = {B, C} ≠ ∅ → **生成割 C={B,C}**：Y_B,3 + Y_C,3 ≤ 1（式5-9） |

割后重解（A11，`src/planning/milp_model.py`）：比较 移B（Back 14×8=112）与
移C（Back 6×12=72）→ **保B移C**：q_3=(0,14,0)、Back_C,3=6、q_4=(8,0,6)；
割仅作用于 t=τ=3（t=4 的 C 不受限）。冻结后 ℋ_3^inf 清空，ℋ_4^inf,(0)=∅（A12）。

## 结论与回填建议

两个滚动周期行为分离：**τ=1 加班型（上限内）→ 不生成割；τ=3 结构型
（上限外 + 单产品移除可恢复）→ 生成割**，与金标设计目的一致，判据可计算、
中间量可复现（`pytest -m regression`）。

建议在论文 §5.2.1 判据②末尾补一句（数值验证已完成，可回写）：

> 若 OT^{*,(k)} ≤ OT_τ^max（等价于 ρ^{*,(k)} > 0），亦判为加班型，
> 不进入单产品移除测试。
